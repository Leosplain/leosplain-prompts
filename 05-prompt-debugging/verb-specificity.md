# Prompt 除錯｜動詞寫太寬還是寫死一點

**長尾問題**：為什麼我的 Prompt 一分析就變成作文？

**改法核心**：把「分析／整理／給建議」改成可檢查的動作：挑出 N 項、附原文依據、找不到就寫無，並禁止客套與空話。

---

## 版本 A（容易空話）

```
你是一位助手。請分析下面這段專案討論，幫我整理重點並給建議。

[貼上討論文字]

請整理重點與建議。
```

## 版本 B（結構化，較可對原文）

```
請只根據下面文字完成任務，不要超出原文。

1. 挑出最多 3 個「已出現的具體共識」；每一點 1 句，下一句寫「原文依據：…」
2. 找不到就寫「無」，不要自己發明共識
3. 列出原文有提到但還沒決定的事（最多 3 點）；沒有則寫「無」

不要客套、不要空話、不要原文沒有的推測。

輸出：
## 共識
1. …
   原文依據：…
## 未決事項
- …

[貼上討論文字]
```

---

**實測觀察**：
- 版本 A：結構完整，像顧問報告；但大量「建議」不是會上已拍板，事實與意見黏在一起。
- 版本 B：明確共識偏少，其餘多在未決；短、可對原文。
- **怎麼選**：要建議稿偏 A；要進紀錄的事實層偏 B。
