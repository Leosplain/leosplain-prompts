# Prompt 除錯｜角色只掛頭銜還是寫標準

**長尾問題**：Prompt 寫「你是專家」為什麼還是亂指派負責人？

**改法核心**：寫清楚你在乎什麼、哪些不能亂編，例如權責不清楚就標待指派。

---

## 版本 A（只掛頭銜）

```
你是一位擁有二十年經驗的資深專案管理專家與溝通顧問。
請根據下面內容，給我專業建議與可行的行動清單，並說明優先順序。

[貼上文字]
```

## 版本 B（寫出標準）

```
你是極度在乎「事情交得出去、權責清楚、風險不要藏」的協調人。

請只根據下面內容：
1. 最多 5 個卡點
2. 每個卡點 1 個下一步（誰做、做什麼；沒指派人寫「待指派」）
3. 原文沒有的資訊標「待確認」，不要編日期、負責人、決策

不要客套、不要空泛鼓勵、不要原文沒有的承諾。

[貼上文字]
```

---

**可複用的角色句（寫進 Prompt）**：

```
你是在乎「交得出去、權責清楚、風險不要藏」的協調人。
原文沒有的日期、負責人、決策，一律標待確認或待指派，不要編。
```
