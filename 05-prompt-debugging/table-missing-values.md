# Prompt 除錯｜表格填滿還是允許待確認

**長尾問題**：為什麼我的 Prompt 一整理表格就亂補日期？

**改法核心**：允許「待確認」，並明確禁止推估與「大家／團隊」當負責人。

---

## 版本 A（易逼出推估）

```
請閱讀下面文字，整理待辦清單。
輸出表格：任務｜負責人｜完成日｜備註
盡量完整；每一列都要填滿；資訊不足請依常理推估後填入。

[貼上文字]
```

## 版本 B（結構化缺值）

```
請只根據下面文字列出明確要做的事，只輸出表格。

| 任務 | 負責人 | 完成日 | 備註 |

規則：
1. 任務要能對到原文；閒聊不要列
2. 負責人只能是一個人的名字；沒有就「待確認」
3. 完成日只有原文有寫才填；否則「待確認」，不要推日期
4. 備註只寫原文有的限制；沒有填「—」
5. 不要用「相關單位」「大家」「團隊」當負責人

[貼上文字]
```

---

**可直接貼進 Prompt 的缺值條款**：

```
負責人只能是一個人的名字；原文沒有就填「待確認」。
完成日只有原文有寫才填；否則「待確認」，不要推日期。
不要用「相關單位」「大家」「團隊」當負責人。
```
