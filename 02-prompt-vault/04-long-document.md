# MODULE 04｜長篇報告與技術資料「標籤隔離閱讀法」

**適用情境**：面對上千字的長文、白皮書或外媒報告。強制 AI 引用原文再做解釋，杜絕模型胡言亂語。

**核心輸出**：引用原文原句 ＋ 兩句話解讀。

---

## Prompt 卡片（複製即可使用）

```
<instructions>
請仔細閱讀下方 <document> 內的長篇資料，歸納出最關鍵的 3 個實質重點。

嚴格執行的規則：
1. 針對每項重點，必須先在 <quote> 標籤內摘錄文章中的原文句子作為證據。
2. 緊接著在 <summary> 標籤內，用 2 句話以內的通俗白話解釋該重點的意義。
3. 若資料中未提及相關問題，請直接標註「原文未提供」，嚴禁自行猜測。
</instructions>

<document>
[貼上長篇報告或文章內容]
</document>
```
