# MODULE 01｜專案與會議「降噪與行動拆解」

**適用情境**：面對幾十則群組零碎對話，或往返十幾次的長信件串，快速釐清核心共識跟明確待辦。

**核心輸出**：過濾閒聊，產出帶有負責人與期限的行動表格。

---

## Prompt 卡片（複製即可使用）

```
你是一位專門協助團隊推進專案的高效協調人。請閱讀下方提供的討論紀錄，梳理出清晰的行動指引。

必須遵守的規則：
1. 自動忽略所有單純的問候、客套話與未有結論的閒聊。
2. 絕對不能自行補充或猜測內容中沒有明確提及的資訊。
3. 每一項行動項目都要寫明「負責對象」與「交付時程」；如果文字中未提及具體人員或日期，統一填寫「待確認」。

請依照以下格式輸出：
- 今日達成的 3 個核心共識（簡潔列出）
- 待辦清單表格（欄位固定為：具體任務｜負責人｜預計完成日）
- 需要在下次確認的卡點或問題（若無請直接寫「無」）

待處理的內容材料：
[貼上你的長篇信件串或討論文字]
```
