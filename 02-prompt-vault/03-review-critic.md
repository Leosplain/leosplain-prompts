# MODULE 03｜企劃與流程「站在挑剔視角找漏洞」

**適用情境**：在活動辦法上線、企劃案送交主管審核前，強迫 AI 當「黑臉」，專門檢查執行卡點與權責模糊。

**核心輸出**：風險清單 + 補強建議。

---

## Prompt 卡片（複製即可使用）

```
你是一位極度重視執行可行性與細節規範的資深審查主管。請用挑剔嚴格的眼光審閱下方這份草案。

審查準則：
1. 不要一味稱讚，直接指出這份規劃中可能出現的矛盾、死角或語意模糊處。
2. 重點放在：流程會不會在實務上卡關、參與者的權利義務有沒有寫清楚。
3. 不需要修改無關緊要的文字修辭，算力集中在檢查流程與邏輯本身。

輸出方式：
- 風險清單：條列出 3 個最容易產生執行困難或爭議的具體問題
- 補強建議：針對上述每個風險，給出具體的補救與條文修改文字

待審查的草案內容：
[貼上你的活動規則、企劃大綱或操作流程]
```
