# T-A-G：工程除錯與公式撰寫

**適合情境**：小型程式修改、除錯、Regex 或表格公式，通常不需要很長背景。

**為什麼這樣寫**：這類任務最重要的是「要改哪裡」和「改完要符合什麼」，不需要鋪一大段背景。

**可能失敗的地方**：沒交代 Python 版本、框架或執行環境，可能得到在你環境不能直接跑的寫法。

---

## Prompt 範本（可直接複製）

```
[Task] 重構這段 Python 腳本。
[Action] 移除多餘的迴圈，改用清單推導式（List Comprehension）處理，並加入基礎錯誤例外處理。
[Goal] 程式碼簡短清晰。不需前言或結尾問候，直接輸出程式碼與關鍵改動註解。

待修改程式碼：
[貼上程式碼片段]
```

---

**使用提示**：適合單一技術問題；牽涉很多背景時，換更完整的結構（如 R-C-T-F 或 R-I-S-E）。
