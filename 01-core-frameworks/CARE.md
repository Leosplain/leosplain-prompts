# C-A-R-E：指定語氣與範例示範（Few-shot）

**適合情境**：公告、客戶回信，或需要維持固定語氣的文字。

**為什麼這樣寫**：直接給認可的範例，比一直寫「親切一點」「自然一點」更有效。

**可能失敗的地方**：範例本身不好，模型也可能把那些寫法一起學走。

---

## Prompt 範本（可直接複製）

```
[Context] 我們正在撰寫一則後台維護通知，讀者為網站用戶，希望語氣平實清晰。
[Action] 將下方這段工程師除錯紀錄，改寫為簡短的公告文字。
[Result] 讀者能清楚了解網站何時暫停服務，且知道資料不受影響。
[Example]
參考範例：「今晚 11 點我們會進行伺服器維護，預計暫停服務 30 分鐘。期間資料不受影響，維護完成後即可正常使用。」

待改寫文字：
[貼上原始工程紀錄]
```

---

**使用提示**：有固定文風時很有用；沒有可參考範例時，不用硬套。
